Nama: CurhaTI

Platform aspirasi anonim mahasiswa Teknologi Informasi Universitas Muhammadiyah Semarang.

- Laravel 12
- Blade Template
- Bootstrap 5
- Bootstrap Icons
- MySQL
- CSS Custom
- JavaScript Vanilla

- React
- Vue
- Tailwind
- Livewire
- Inertia
- Alpine

Anonymous

## Rules

Jangan mengubah:

- Route yang sudah ada
- Authentication
- Database yang sudah berjalan

Jangan membuat framework baru.

Gunakan Bootstrap 5.

Gunakan Blade.

Gunakan Bootstrap Icons.

Pertahankan struktur project.

---

## Code Style

Gunakan:

- Controller bersih
- Model sederhana
- Validasi Laravel
- Best Practice Laravel

Jangan membuat kode berulang.

---

## Response

Jika diminta membuat fitur:

- edit seminimal mungkin
- jangan merusak fitur lain
- jangan menghapus CSS yang sudah ada
- gunakan komponen yang sudah tersedia
